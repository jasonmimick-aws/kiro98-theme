# Kiro 98

A late-90s desktop theme pack for [Kiro Crew](https://github.com/kirodotdev/KiroCrew):
silver bevels, a navy title bar, pixel fonts, an hourglass loader, a boot splash,
a startup chime and an idle starfield screensaver.

## Install

Settings → Display → Install theme, then give it either:

- this folder's path, or
- this repo's GitHub URL.

Pick **Kiro 98** in the theme list. On first activation Kiro Crew asks which
experience parts to turn on: **Sounds**, **Overlays** (the screensaver) and
**Persona** (a light retro tone). Each one is optional.

Fonts: under Settings → Display → Font Family, choose **Sans** for the pixel UI
font or **System** to keep your OS font. Code and the terminal use VT323.

## What's in the pack

| Part | File |
|---|---|
| Palette, light (classic silver) + dark (black wells) | `variables.json` |
| Bevels, title bar, square corners, scrollbars | `styles/overrides.css` |
| Pixelify Sans (UI), VT323 (code) | `styles/fonts/` |
| Logo, favicon, welcome monitor, boot splash | `branding/` |
| Hourglass loader | `loader/hourglass.svg` |
| Starfield screensaver after 3 idle minutes | `overlays/screensaver.html` |
| Startup chime, notification ding, error bonk | `audio/` |
| Retro tone (optional) | `persona.md` |

All art and sounds are original and generated by `.github/scripts/build_assets.py`.

## Limits

Theme packs can only restyle Kiro Crew's stable hooks. Other buttons, menus and
dialogs keep their stock shapes but pick up the palette and square corners.
